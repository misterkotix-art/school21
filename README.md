## Добавление новых работ

Домашние работы размещаются в `homework/<предмет>/homework-<номер>/`, итоговые проекты в `projects/<предмет>/<название>/`. Для каждой работы используется отдельная папка. Названия папок пишутся латиницей в нижнем регистре, слова разделяются дефисом.

В папке работы находятся выполненный ноутбук, разрешённые к публикации исходные данные, короткий `README.md` с описанием запуска и `requirements.txt` с зависимостями, если они нужны. Ноутбук сохраняется с результатами ячеек и графиками. Пути к данным задаются относительно папки работы.

После добавления работы нужно внести её в таблицу выше. Общие настройки репозитория не привязаны к одному предмету. Ключи доступа, файлы `.env`, временные файлы и виртуальные окружения в репозиторий не добавляются. Учебные CSV и выполненные `.ipynb` сохраняются.
