# Сессионный проект. Внедрение алгоритма выбора слота доставки

Сосновский Егор, М26-515.

Решение: модифицировать алгоритм и повторить пилот. В синтетическом сценарии конверсия выросла на 1,246 п.п., 95% интервал от 1,062 до 1,429 п.п. Ошибки выросли на 0,554 п.п., что превышает заданный допустимый рост +0,2 п.п.

- [Выполненный ноутбук](delivery_slot_rollout.ipynb): все расчёты, три графика и выводы сохранены.
- [Исходный CSV](delivery_slots_city_day.csv): 3360 наблюдений по 40 городам за 84 дня, seed 20261103.
- [Открыть в Colab](https://colab.research.google.com/github/misterkotix-art/school21/blob/main/projects/ab-testing/delivery-slot-rollout/delivery_slot_rollout.ipynb).

Метод: DiD с эффектами города и даты, стандартные ошибки сгруппированы по городам. Выполнены проверка предтрендов, сравнение четырёх спецификаций, анализ защитной метрики и сравнение с наивными оценками. Данные учебные, вывод не относится к реальному сервису.

## Запуск

В Colab откройте ноутбук по ссылке выше, скачайте CSV и загрузите его через панель «Файлы» в рабочую среду. Сохраните имя `delivery_slots_city_day.csv`, затем выберите «Среда выполнения» → «Выполнить все». Ноутбук только читает готовые данные.

Для локального запуска положите ноутбук и CSV в одну рабочую папку Jupyter, выполните `pip install -r requirements.txt` и запустите все ячейки. В зависимостях указаны версии проверенного запуска.

Для комментариев к работе откройте историю файла на GitHub и выберите коммит его публикации. Комментарии включены, нужен вход в аккаунт GitHub.
