# Домашнее задание №2. Аудит A/B-эксперимента

Сосновский Егор, М26-515.

Решение: повторить эксперимент с изменениями. После коррекции состава групп по выходным разница конверсий равна -0,045 п.п., 95% интервал от -1,841 до +1,752 п.п. Частота ошибок выросла с 1,94% до 5,53%.

- [Выполненный ноутбук](experiment_audit.ipynb): расчёты, выводы и пять графиков сохранены.
- [Исходный CSV](exp_data_seed_195600.csv): 6585 синтетических наблюдений, seed 195600.
- [Открыть ноутбук в Colab](https://colab.research.google.com/github/misterkotix-art/school21/blob/main/homework/ab-testing/homework-02/experiment_audit.ipynb).

В работе проверены качество данных, SRM, баланс weekend, конверсия, частота ошибок, три платформы с поправкой Бонферрони и время входа. Коррекция выполнена через стратификацию по weekend. Ограничения проверки peeking разобраны в ноутбуке.

## Повторный запуск

В Colab откройте ноутбук по ссылке выше. Скачайте CSV из этой папки и загрузите его через панель «Файлы» в рабочую среду Colab. Имя файла должно остаться `exp_data_seed_195600.csv`. Затем выберите «Среда выполнения» → «Выполнить все».

Локально положите ноутбук и CSV в одну рабочую папку Jupyter. Установите библиотеки командой `pip install -r requirements.txt` и выполните все ячейки. В `requirements.txt` указаны версии библиотек, на которых проверен сохранённый результат.

Ноутбук читает готовый CSV и не генерирует данные заново. CSV хранится отдельно от ноутбука.
